# Rishabh Rawat — Portfolio Website

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Before publishing
- Replace `your.email@example.com` in `index.html` with your email address.
- Update the GitHub and LinkedIn profile links.
- Replace the sample project link with the actual calculator repository URL.
- Edit the About and Skills sections to match your current experience.

## Publish with GitHub Pages
1. Push these files to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. GitHub Pages will provide your website URL after deployment.

## Files
- `index.html` — page content
- `style.css` — responsive design
- `script.js` — mobile navigation
- `assets/profile.jpg` — portfolio portrait
